# Catálogo de modelos

Fichas breves de los modelos evaluados para MedIA. No contiene código
ejecutable; sirve para comparar capacidades, licencias, proveedores y requisitos.

| Carpeta | Modelos evaluados para |
| --- | --- |
| `audio/transcripcion/` | Transcripción y diarización. |
| `audio/tts/` | Síntesis y clonación de voz. |
| `avatares/` | Avatares parlantes. |
| `multimedia/` | Consulta y adaptación multimodal. |
| `video/` | Generación de vídeo. |

Cada archivo Markdown corresponde a un modelo e incluye, cuando está
disponible:

- propósito y capacidades;
- licencia e idiomas;
- proveedor o forma de despliegue;
- requisitos y notas de integración;
- enlaces a documentación o demostraciones.

Las fichas documentan alternativas evaluadas; no implican que el modelo esté
integrado en el código. Los modelos usados actualmente se configuran desde
`services/media-core/.env`.
