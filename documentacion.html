MedIA / Guía completa

Instala, arranca y utiliza el archivo audiovisual.

Documentación autónoma basada en el README raíz y en las guías de Media Core, Media API y Media Web.

Este archivo funciona sin servidor. Sigue la instalación una vez; para el uso diario solo tendrás que arrancar los servicios.

Arquitectura y puertos

La interfaz coordina varios procesos. Cada componente debe apuntar al siguiente servicio.

Media Web · 3000Biblioteca, chat, avatar y panel de uso.
Media API · 8010Subidas, trabajos, historial, cola y puente con Hermes.
Media Core · 8001/mcpÍndices, búsqueda y procesamiento audiovisual.
Hermes · perfil localInterpreta peticiones y utiliza las herramientas MCP.
La API inicia Hermes cuando hace falta. No necesitas dejar abierto hermes chat, ejecutar un gateway ni instalar su escritorio.

Requisitos

SoftwareGit, uv, Python 3.11, Node 24 LTS o Node 22 reciente, npm, FFmpeg y FFprobe.
Equipo16 GB de RAM como orientación, 32 GB recomendados para indexar.
Espacio15-25 GB iniciales, además del tamaño de los vídeos.
SistemasWindows PowerShell, macOS o Linux. WSL2 debe contener toda la instalación.
Comprobar herramientas
git --version
node --version
npm --version
uv --version
ffmpeg -version
ffprobe -version
uv python install 3.11

En Windows utiliza npm.cmd si PowerShell bloquea npm.ps1. No hace falta activar manualmente los entornos.

Instalar dependencias

Ejecuta todo desde la raíz de un clon nuevo. Cada componente mantiene su propio entorno y lock.

git clone <URL_DEL_REPOSITORIO> MedIA
cd MedIA

cd services/media-core
uv sync --python 3.11 --locked --extra dev
cd ../..

cd services/media-api
uv sync --python 3.11 --locked --extra dev
cd ../..

cd docker/hermes-agent
uv sync --python 3.11 --locked --extra mcp
cd ../..

cd apps/media-web
npm ci
cd ../..
No uses uv add, uv lock --upgrade ni npm update para preparar un clon. No copies .venv entre equipos.

Claves y configuración

FAL_ADMIN_KEYConsulta opcional de gasto FAL.

Configuración esencial de la API
HERMES_MODE=local
MEDIA_GENERATION_BACKEND=hermes
HERMES_AGENT_DIR=/ruta/MedIA/docker/hermes-agent
HERMES_PYTHON=/ruta/MedIA/docker/hermes-agent/.venv/bin/python

Configuración del frontend
MEDIA_API_URL=http://127.0.0.1:8010

Es opcional con el puerto predeterminado. No definas NEXT_PUBLIC_MEDIA_UPLOAD_URL para conservar la subida por streaming.

Preparar modelos

Los modelos locales se descargan una vez. Los modelos generativos remotos no se guardan en el equipo.

PiperVoces locales en castellano, catalán e inglés.
Whisper localDictado del micrófono. No sustituye WhisperX para vídeos.
MiniLMBúsqueda semántica de transcripciones.
CLIP y OCRBúsqueda visual y lectura de texto visible.
EmbeddingGemma 2Índice multimodal local de unos 1,4 GB.
cd services/media-core
uv run --locked --extra dev python -m media_core.services.piper_tts --download
uv run --locked --extra dev python -m media_core.services.local_voice --download
uv run --locked --extra dev python -m media_core.indexing
cd ../..
No ejecutes --rebuild en cada arranque. Detén Core antes de reconstruir una colección.

Configurar Hermes

  1. Selecciona el perfil.Usa data/state/hermes como HERMES_HOME.
  2. Configura el modelo.Ejecuta hermes setup y hermes model con un modelo que admita herramientas.
  3. Carga las skills.Añade la ruta absoluta shared/skills a skills.external_dirs.
  4. Instala la skill general.Copia media-video-archive.md como SKILL.md dentro del perfil.
  5. Conecta Core.Registra el MCP con el nombre exacto media-core.
export MEDIA_REPO="$(pwd)"
export HERMES_HOME="$MEDIA_REPO/data/state/hermes"
export MEDIA_HERMES_CLI="$MEDIA_REPO/docker/hermes-agent/.venv/bin/hermes"
mkdir -p "$HERMES_HOME"
hermes() { "$MEDIA_HERMES_CLI" "$@"; }
hermes setup
hermes model
El código está en docker/hermes-agent, pero el modo local no obliga a utilizar Docker.

Arranque local

Inicia Core primero. Después arranca API y web, manualmente o con el lanzador.

# Terminal 1: Media Core
cd services/media-core
uv run --locked --extra dev python server.py

# Terminal 2: API y web en macOS/Linux
bash scripts_arranque/start-media-web.sh

# Windows
.\scripts_arranque\start-media-web.ps1
Arranque manual en tres terminales
# Core
cd services/media-core
uv run --locked --extra dev python server.py

# API
cd services/media-api
uv run --locked --extra dev uvicorn app.main:app --host 127.0.0.1 --port 8010

# Web
cd apps/media-web
npm run dev
El lanzador no instala ni arranca Core y tampoco configura Hermes. No ejecutes a la vez el arranque manual y el lanzador.

Comprobar el estado

curl --fail http://127.0.0.1:8010/api/health

hermes mcp add media-core --url http://127.0.0.1:8001/mcp
hermes mcp test media-core
hermes tools list --platform cli
hermes skills list

hermes_running=false puede ser normal antes del primer mensaje. Una conversación real prueba la clave, el modelo, las skills y las herramientas.

Uso diario y parada

  1. Arranca Core.Espera al puerto 8001.
  2. Arranca API y web.Usa el lanzador o terminales separadas.
  3. Abre la aplicación.Visita http://127.0.0.1:3000.
  4. Detén con seguridad.Espera las tareas, detén web/API y finalmente Core.

Los índices y archivos guardados permanecen. Los trabajos activos en memoria se interrumpen al parar Core.

Flujo recomendado

  1. Añade un vídeo corto.Empieza con 30-60 segundos y audio comprensible.
  2. Espera la transcripción.La búsqueda textual se activa primero.
  3. Prepara el índice.La cola habilita imagen, sonido y vídeo.
  4. Pregunta o crea.Busca, resume, recorta, dobla o subtitula.
  5. Verifica.Reproduce el tramo final y contrasta contenido y tiempos.

Biblioteca y subidas

FormatosMP4, MOV, MKV, WEBM y M4V legibles por FFprobe.
Límite4.096 MB por defecto, configurable con MEDIA_UPLOAD_MAX_MB.
Streaming/api/videos transmite el archivo sin depender del límite de Next.js.
IdentidadVídeo y transcripción deben compartir ID, por ejemplo TV04.

Desde cada ficha puedes reproducir, consultar progreso, preparar índices, reintentar o eliminar el vídeo y sus datos derivados.

Indexación y búsqueda

TextoMiniLM busca en lo pronunciado.
VisualCLIP y OCR localizan objetos, acciones y rótulos.
MultimodalEmbeddingGemma 2 compara texto, imagen, audio y vídeo.
ReferenciasUn archivo por mensaje, hasta 50 MB y 30 segundos.
/buscar TV04 dónde se oye un aplauso
/buscar-visual TV04 cuándo aparece un rótulo azul
/indexar TV04
/indexar-visual TV04

Los adjuntos temporales se eliminan al terminar o cancelar. Puedes seguir buscando por transcripción mientras se completa el índice multimodal.

Crear entregables

/doblar TV04 del segundo 30 al 45 al inglés
/subtitular TV04 del segundo 30 al 45
Dame un clip de TV04 del segundo 30 al 45, dóblalo y añade subtítulos en inglés.
ClipsCortes por tiempo, tema, persona o aparición visual.
DoblajeTraducción por segmentos. Conserva duración y ambiente; no modifica los labios.
SubtítulosTexto original o traducido, MP4 visible y SRT.
IdiomasPiper admite es, ca y en. Otros idiomas requieren un proveedor compatible.
Para doblar y subtitular el mismo clip, completa primero el doblaje y utiliza ese MP4 como fuente.

Voz y avatar

HablarUna pausa de 1,4 segundos termina, transcribe y envía.
DictadoMáximo 60 segundos y 8 MB.
Referencia sonoraGraba una muestra de hasta 30 segundos.
NavegadorEl micrófono requiere localhost, 127.0.0.1 o HTTPS.

Para diagnosticar consulta http://127.0.0.1:8010/api/voice/status.

Resolver problemas

Core no conecta

Comprueba 8001, que MEDIA_MCP_URL termina en /mcp y ejecuta hermes mcp test media-core.

Hermes no ve herramientas

Revisa las rutas de Hermes, el mismo HERMES_HOME, skills.external_dirs y los toolsets.

Error de OpenRouter o Replicate

Revisa clave, modelo y saldo. 401/403 suele ser acceso, 402 saldo y 429 límites.

No hay transcripción o hablantes

Comprueba Replicate, la pista de audio y el token HF. La subida no activa diarización por defecto.

La búsqueda no encuentra nada

Revisa cobertura, vídeo, transcripción, disco, FFmpeg y EmbeddingGemma 2. Reintenta desde la biblioteca.

Falla doblaje o subtitulado

Comprueba diálogo, FFmpeg, OpenRouter y voz de destino. Puedes fijar MEDIA_SUBTITLE_ENCODER=libx264.

El avatar no responde

Repite las descargas de Piper y Whisper, revisa permisos y consulta /api/voice/status.

Subida fallida

Comprueba API, FFprobe, disco, límite y que la ruta de streaming sea /api/videos.

Puerto ocupado
lsof -nP -iTCP:3000 -iTCP:8010 -iTCP:8001 -sTCP:LISTEN

cd ../../services/media-api && uv run --locked --extra dev pytest -q
cd ../../apps/media-web && npm test && npm run typecheck && npm run build

Detén el servidor de desarrollo antes de compilar. Completa la prueba con material autorizado y reproducción real de los resultados.

Datos y privacidad

data/test-vectors/videosVídeos locales.
data/modelsModelos y voces.
data/indexesÍndices ChromaDB.
data/cacheTranscripciones, OCR y progreso.
data/outputsClips, doblajes, subtítulos y audio.
data/stateHistorial, temporales y perfil Hermes.

No guardes en Git claves, entornos, pesos, vídeos, cachés, resultados ni perfiles personales. Algunas funciones envían la información necesaria a proveedores remotos.
