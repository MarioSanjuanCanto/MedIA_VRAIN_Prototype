# Skills de Media Core

Skills de Hermes para procesar, buscar, resumir, indexar, recortar y sintetizar
contenido audiovisual mediante el MCP de Media Core.

| Ruta | Capacidad |
| --- | --- |
| `process/` | Flujo general de procesamiento. |
| `search/` | Búsqueda en transcripciones. |
| `summarize/` | Resúmenes. |
| `clips/` | Selección y generación de clips. |
| `tts/` | Síntesis de voz. |
| `video-indexing/` | Indexación de vídeos. |
| `visual/` | Búsqueda visual multimodales (CLIP) y descripción con VLM. |
| `visual-indexing/` | Análisis de escenas, fotogramas clave e índice visual. |
| `visual-search/` | Búsqueda visual rápida o exhaustiva. |
| `scene-tools/` | Descripción, recorte e identificación en escenas concretas. |
| `ocr/` | Extracción de texto visible en pantalla. |
| `speakers/` | Identificación de hablantes y turnos de palabra. |
| `server-info/` | Estado del servidor. |
| `media-video-archive.md` | Uso del archivo audiovisual. |

Estas skills describen cómo usar las herramientas; el código que las ejecuta
vive en `services/media-core/`.
